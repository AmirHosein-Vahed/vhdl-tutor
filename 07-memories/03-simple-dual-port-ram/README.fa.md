# 03 — RAM سادهٔ دو‌درگاهه

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [07-memories — حافظه‌ها](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

درگاه دومی برای خواندن و نوشتن هم‌زمان اضافه کن و حالت برخورد را صریح مدیریت کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(posedge clk) begin mem[wa] <= wd; rd <= mem[ra]; end` | `process (clk) begin if rising_edge(clk) then mem(wa) <= wd; rd <= mem(ra); end if; end process;` |

## مفاهیم

- دو‌درگاههٔ ساده یعنی یک درگاه نوشتن و یک درگاه خواندن؛ دو‌درگاههٔ واقعی یعنی دو تا از هر کدام.
- برخورد (آدرس یکسان، چرخهٔ یکسان) رفتار وابسته به ابزار دارد؛ در کدت تعریفش کن.
- RAM دو‌درگاهه همان چیزی است که با آن بافر فریم یا FIFO با ساعت‌های مستقل می‌سازند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. درگاه A را بنویس و درگاه B را با نرخ متفاوت بخوان و ثابت کن داده‌ای گم نمی‌شود.
2. خروجی write-through اضافه کن تا خواندن آدرس نوشته‌شده مقدار جدید را برگرداند.
