# 02 — RAM تک‌درگاهه

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [07-memories — حافظه‌ها](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

الگوی متعارف RAM با نوشتن هم‌زمان و خواندن هم‌زمان را بنویس که روی هر FPGA به بلوک RAM نگاشت شود.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `reg [7:0] mem [0:255];` | `type ram_t is array (0 to 255) of std_logic_vector(7 downto 0);` |

## مفاهیم

- ‎if rising_edge(clk) then if we then mem(addr) <= d; q <= mem(addr); end if; — یک ساعت، یک درگاه.
- خواندن و نوشتن هم‌زمان در شبیه‌سازی مقدار قبلی را برمی‌گرداند مگر خلافش را مشخص کنی؛ مستندش کن.
- خواندن ناهم‌زمان (q <= mem(addr) بیرون ساعت) RAM توزیع‌شده می‌سازد، نه بلوک RAM.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. ۱۶ آدرس را بنویس و بخوان، سپس محتوای حافظه را چاپ کن و با انتظار مقایسه کن.
2. خواندن را ناهم‌زمان کن و مصرف منابع سنتزشده را مقایسه کن.
