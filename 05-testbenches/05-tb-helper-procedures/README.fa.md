# 05 — کمک‌تابع‌های قابل استفادهٔ مجدد بستر آزمون

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [05-testbenches — بسترهای آزمون](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

محرک و بررسی تکراری را به یک بسته (tb_utils) منتقل کن تا بسترهای آزمون مثل نقشهٔ آزمون خوانده شوند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `task automatic drive(input logic [7:0] d);` | `procedure drive(signal d : out std_logic_vector);` |

## مفاهیم

- رویه‌های درون بسته می‌توانند سیگنال را به‌عنوان پارامتر signal بگیرند و آن را برانند.
- سربارگذاری اجازه می‌دهد یک رویهٔ check هم std_logic و هم unsigned و هم integer را بپذیرد.
- بستهٔ مشترک همان روشی است که تیم‌های VHDL بدون چارچوب، BFM می‌سازند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. سربارگذاری‌های check_eq را برای unsigned و integer به common/vhdl/tb_utils.vhd اضافه کن.
2. رویهٔ send_byte بنویس که فرستندهٔ UART را براند و آن را در دو بستر آزمون به کار ببر.
