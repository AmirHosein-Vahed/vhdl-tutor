# 03 — ورودی/خروجی فایل و جنریک‌های بستر آزمون

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [05-testbenches — بسترهای آزمون](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

بردارها را با textio از یک فایل متنی بخوان و یک بستر آزمون را به همهٔ پیکربندی‌های DUT خدمتکار کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `$readmemh("vec.hex", mem);` | `readline(f, l);  read(l, v);` |

## مفاهیم

- ieee.std_logic_textio توابع read و write برای std_logic_vector می‌دهد؛ std.textio خطوط را مدیریت می‌کند.
- تا endfile بخوان و خطوط را بشمار تا فایل بدشکل با خطا شکست بخورد.
- عرض، ساعت و فایل بردار را از جنریک بگیر — بستر آزمون به ابزاری قابل استفادهٔ مجدد تبدیل می‌شود.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. فایلی با ۳۲ بردار بنویس، به ALU بده و همهٔ خروجی‌ها را بررسی کن.
2. جنریک VEC_FILE اضافه کن تا با ‎-gVEC_FILE=... مجموعهٔ بردار دیگری انتخاب شود.
