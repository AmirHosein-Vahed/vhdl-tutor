# 05-testbenches — بسترهای آزمون

**وضعیت:** 0 از 5 درس نوشته شده · [نقشهٔ راه](../../README.fa.md) · [English](README.md)

## چرا این موضوع

بستر آزمون جایی است که VHDL در آزمون از وریلاگ جلو می‌زند. این موضوع محرک‌های دستی را به آزمون‌های تکرارپذیر، خودبررسی و محافظت‌شده با تایم‌اوت تبدیل می‌کند — پایهٔ همهٔ موضوع ۱۱.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always #5 clk = ~clk;` | `clk <= not clk after 5 ns;` |
| `if (y !== e) $error("...");` | `assert y = e report "..." severity warning;` |
| `$readmemh("vec.hex", mem);` | `readline(f, l);  read(l, v);` |
| `#1000 $finish;` | `wait for 1 us;  std.env.finish;` |
| `task automatic drive(input logic [7:0] d);` | `procedure drive(signal d : out std_logic_vector);` |

## پس از این موضوع می‌توانی

- نوشتن بستر آزمونی که بدون دیدن شکل موج قابل اعتماد باشد
- راندن و بررسی DUT از فایل و جنریک
- توقف قطعی شبیه‌سازیِ معلق

## پیش‌نیاز

ابتدا موضوع قبلی را تمام کن؛ هر موضوع مستقیماً روی قبلی ساخته می‌شود.
درس اول کل زنجیرهٔ ابزار را هم توضیح می‌دهد، بنابراین پیش‌زمینهٔ VHDL لازم نیست.
