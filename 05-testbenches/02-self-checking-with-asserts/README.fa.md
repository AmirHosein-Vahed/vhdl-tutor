# 02 — بسترهای خودبررسی

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [05-testbenches — بسترهای آزمون](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

چاپ‌کردن و خیره‌شدن را با assert جایگزین کن: شکست‌ها را بشمار، یک خلاصه چاپ کن و در شکست با کد غیرصفر خارج شو.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `if (y !== e) $error("...");` | `assert y = e report "..." severity warning;` |

## مفاهیم

- دستور assert شرط report پیام severity سطح تنها ابزار آزمونی است که لازم داری.
- برای شکست‌های تکی از severity warning استفاده کن تا اجرا ادامه یابد و برای خلاصه از severity failure.
- std.env.finish خروج تمیز می‌دهد؛ finish(1) کد خروج غیرصفر برای CI.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. جنریک verbose اضافه کن که در حالت true هر بردار و در حالت false فقط خلاصه را چاپ کند.
2. بستر آزمون تعداد بررسی‌ها را بشمارد و در پایان «N بررسی، M شکست» گزارش کند.
