# 02 — سیگنال در برابر متغیر

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [01-language-basics — مبانی زبان](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

مهم‌ترین تفاوت معنایی با تقسیم blocking/non-blocking وریلاگ را بفهم: سیگنال زمان‌بندی می‌شود، متغیر بلافاصله اثر می‌کند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(*) begin t = a; y = t; end  // blocking` | `process (all) variable t : std_logic; begin t := a; y <= t; end process;` |

## مفاهیم

- انتساب سیگنال، به‌روزرسانی را برای پایان چرخهٔ دلتای جاری زمان‌بندی می‌کند.
- انتساب متغیر در خط بعدی و در همان اجرای فرایند اثر می‌کند.
- متغیر را برای مقادیر میانی ترکیبی درون یک فرایند به کار ببر؛ سیگنال را برای هر چیزی که از مرز فرایند می‌گذرد.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. جابه‌جاکنندهٔ موضوع ۰۰ را با متغیر بازنویسی کن و تفاوت خروجی را توضیح بده.
2. یک خط لولهٔ ترکیبی سه‌مرحله‌ای فقط با سیگنال بساز؛ تعداد چرخه‌های دلتای لازم برای پایدارشدن را بشمار.
