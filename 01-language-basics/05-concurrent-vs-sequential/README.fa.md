## هدف

ببین که y <= a and b; خودش یک فرایند است و when و with و case و if توصیف‌های جایگزینِ یک سخت‌افزارند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `assign y = s ? b : a;` | `y <= b when s = '1' else a;` |
| `case (s) ... endcase` | `with s select y <= ... ;` |

## مفاهیم

- انتساب‌های هم‌زمان به فرایندهای ضمنی حساس به سمت راست تبدیل می‌شوند.
- when ... else انتساب شرطی است؛ with ... select انتساب انتخابی؛ case به فرایند نیاز دارد.
- process (all) در VHDL-2008 جای فهرست حساسیت دستی را می‌گیرد و ناسازگاری شبیه‌سازی را کم می‌کند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک مالتی‌پلکسر ۴ به ۱ را به سه روش پیاده کن و تأیید کن منطق سنتزشده یکسان است (موضوع ۱۰).
2. فرایندی با فهرست حساسیت ناقص بنویس، ناسازگاری را ببین، سپس با process (all) درستش کن.
