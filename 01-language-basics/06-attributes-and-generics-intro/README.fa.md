> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

به‌جای اعداد جادویی از ویژگی‌ها و به‌جای ویرایش ثابت‌ها پیش از هر ساخت از جنریک‌ها استفاده کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `parameter WIDTH = 8` | `generic (WIDTH : positive := 8)` |
| `#(.WIDTH(16))` | `generic map (WIDTH => 16)` |

## مفاهیم

- عبارت clk'event and clk='1' همان چیزی است که rising_edge(clk) پنهان می‌کند؛ stable و image و range معادل وریلاگی ندارند.
- جنریک پارامتر زمان کامپایل است و درگاه سیم زمان اجرا؛ generic map در بسط و port map برای اتصال سیگنال‌هاست.
- جنریک می‌تواند بازه، عرض، قطبیت ریست و حتی وجود منطق را تعیین کند (if G_ENABLE generate).

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. عرض و قطبیت ریست شمارنده را پارامتری کن، سپس آن را با دو عرض مختلف در یک بستر آزمون نمونه‌سازی کن.
2. با image یک عدد صحیح را در report چاپ کن، بدون کلنجار با integer'image.
