# 02 — سبک‌های ریست

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [03-sequential — منطق ترتیبی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

ریست هم‌زمان و ناهم‌زمان، فعال‌پایین و فعال‌بالا را مقایسه کن و برای هر طراحی تصمیم بگیر، نه با کپی یک الگو.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(posedge clk or negedge rst_n)` | `process (clk, rst_n) begin if rst_n = '0' then ... elsif rising_edge(clk) then ...` |

## مفاهیم

- ریست ناهم‌زمان فوری اثر می‌کند اما برای رهاسازی به همگام‌ساز نیاز دارد؛ ریست هم‌زمان یک مالتی‌پلکسر در مسیر داده هزینه می‌دهد.
- تولیدکنندگان FPGA ریست هم‌زمان یا ناهم‌زمان با رهاسازی همگام را ترجیح می‌دهند؛ جریان ASIC معمولاً هم‌زمان.
- مقدار اولیه (:= '0') در شبیه‌سازی کار می‌کند اما بازنشانی سخت‌افزاری را تضمین نمی‌کند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. هر دو سبک ریست را پشت یک جنریک پیاده کن و تفاوت شکل موج در زمان صفر را نشان بده.
2. یک همگام‌ساز ریست دو فلیپ‌فلاپی اضافه کن و توضیح بده چه مشکلی را حل می‌کند.
