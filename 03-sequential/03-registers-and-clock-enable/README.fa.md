# 03 — رجیسترها و فعال‌ساز ساعت

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [03-sequential — منطق ترتیبی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک فایل رجیستر بساز و یاد بگیر چرا enable یک if است و هرگز ساعت گیت‌شده نیست.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(posedge clk) if (we) mem[addr] <= d;` | `process (clk) begin if rising_edge(clk) then if we = '1' then mem(addr) <= d; end if; end if; end process;` |

## مفاهیم

- گیت‌کردن ساعت در RTL مشکل دامنهٔ ساعت و زمان‌بندی می‌سازد؛ به‌جایش از فعال‌ساز ساعت استفاده کن.
- فایل رجیستر آرایه‌ای از std_logic_vector با نوشتن هم‌زمان و خواندن ناهم‌زمان است.
- رفتار خواندن و نوشتن هم‌زمانِ یک آرایه در شبیه‌سازی باید صریح باشد.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. فایل رجیستر را دو-نوشتنی کن و ثابت کن دو نوشتن در یک ساعت نتیجهٔ قطعی دارد.
2. مسیر bypass اضافه کن تا خواندن آدرسی که همین حالا نوشته شده، دادهٔ جدید را برگرداند.
