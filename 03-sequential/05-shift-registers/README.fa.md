# 05 — شیفت‌رجیسترها

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

شیفت SISO و SIPO و PISO و سپس یک LFSR را با عملگرهای شیفتی که از وریلاگ می‌شناسی پیاده کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `q <= {q[6:0], d};` | `q <= q(6 downto 0) & d;` |

## مفاهیم

- shift_left و shift_right منطقی‌اند؛ sll و srl شکل قدیمی‌تر عملگرند؛ rotate_left می‌چرخاند.
- شیفت‌رجیستر فقط رجیستری است که مقدار بعدی‌اش الحاق یا برشی از خودش است.
- LFSR شیفت‌رجیستری با بازخورد XOR است — مولد شبه‌تصادفی ارزان برای بستر آزمون.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک شیفت‌رجیستر بشکه‌ای پارامتری بساز و اندازه‌اش را در موضوع ۱۰ با نسخهٔ سری مقایسه کن.
2. با یک LFSR هشت‌بیتی ۱۰۰ بردار شبه‌تصادفی بساز و تکرارها را بررسی کن.
