# 04 — شمارنده‌ها

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

شمارندهٔ بالا/پایین/بارگذاری با شمارش پایانی بنویس و آگاهانه بین integer range و unsigned یکی را انتخاب کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `counter <= counter + 1;` | `count <= count + 1;  -- unsigned` |
| `if (count == N-1)` | `if count = N - 1 then` |

## مفاهیم

- integer range 0 to N-1 در شبیه‌سازی بررسی کران رایگان می‌دهد؛ unsigned حساب و چرخش رایگان.
- شمارش پایانی یک مقایسه با ثابت است، نه دیکد کردن همهٔ بیت‌ها.
- شمارش پیمانه‌ای یک انتساب چرخشی است، نه تقسیم‌کننده.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. پیش‌تقسیم‌کننده اضافه کن تا شمارنده از ساعت ۵۰ مگاهرتز هر میلی‌ثانیه یک بار بشمارد.
2. شمارندهٔ BCD (۰ تا ۹) بساز و دو تا را زنجیره کن تا شمارندهٔ ۰۰ تا ۹۹ به دست آید.
