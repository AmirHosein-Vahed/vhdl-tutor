# 01 — نخستین فرایند ساعت‌دار

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [03-sequential — منطق ترتیبی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک جمع‌کنندهٔ ترکیبی را با یک if rising_edge(clk) به رجیستر تبدیل کن و بفهم چرا چیز دیگری جای آن ندارد.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(posedge clk) q <= d;` | `process (clk) begin if rising_edge(clk) then q <= d; end if; end process;` |

## مفاهیم

- rising_edge(clk) تنها آزمون لبهٔ ساعتی است که باید بنویسی.
- همهٔ انتساب‌های درون فرایند ساعت‌دار رجیستر می‌شوند؛ انتساب‌های بیرون، ترکیبی می‌مانند.
- فرایند ساعت‌دار با ریست ناهم‌زمان دو ورودی حساسیت دارد (clk و rst) و شاخهٔ ریست اول می‌آید.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. enable اضافه کن و کاری کن رجیستر در حالت غیرفعال مقدارش را نگه دارد.
2. rising_edge را با clk'event and clk='1' عوض کن و توضیح بده چرا اولی ترجیح داده می‌شود.
