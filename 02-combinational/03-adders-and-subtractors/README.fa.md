# 03 — جمع‌کننده‌ها و تفریق‌کننده‌ها

**وضعیت:** انجام‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> **آماده.** در این پوشه `make` را اجرا کنید.

## هدف

ساخت جمع‌کننده‌ها و تفریق‌کننده‌های ترکیبی با قابلیت تولید سرریز (carry-out) و تشخیص سرریز علامت‌دار با استفاده از `numeric_std`.

## مفاهیم

- انواع `unsigned` و `signed` از کتابخانه `ieee.numeric_std`.
- تشخیص سرریز علامت‌دار زمانی که دو عملوند با علامت یکسان نتیجه‌ای با علامت مخالف بدهند.

## فایل‌ها

| فایل | هدف |
|---|---|
| `src/adder_subtractor.vhd` | جمع‌کننده/تفریق‌کننده ۸ بیتی |
| `tb/adder_subtractor_tb.vhd` | بستر آزمون خودبررسی |

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج
make clean  # پاک کردن build/
```
