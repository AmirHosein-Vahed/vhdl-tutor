# 01 — مالتی‌پلکسرها: when، with، case

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

مالتی‌پلکسر ۲ به ۱ و ۴ به ۱ را در هر سه سبک بساز و بدان کدام را کجا به کار ببری.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `assign y = s ? b : a;` | `y <= b when s = '1' else a;` |
| `casez (sel)` | `with sel select` |

## مفاهیم

- زنجیرهٔ when/else منطق اولویت است؛ ترتیب مهم است.
- with ... select یک case موازی است: دقیقاً یک شاخه انتخاب می‌شود و باید کامل باشد.
- case درون فرایند، نحو ترتیبی است که سخت‌افزار ترکیبی را توصیف می‌کند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. ورودی valid به مالتی‌پلکسر ۴ به ۱ اضافه کن که خروجی را در حالت صفر نگه دارد.
2. یک when/else تودرتو را به with/select بازنویسی کن و بررسی کن جدول درستی تغییر نکرده.
