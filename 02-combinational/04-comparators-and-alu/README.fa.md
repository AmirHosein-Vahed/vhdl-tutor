# 04 — مقایسه‌کننده‌ها و یک ALU کوچک

**وضعیت:** انجام‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> **آماده.** در این پوشه `make` را اجرا کنید.

## هدف

ساخت یک ALU ترکیبی کوچک که از عملیات حسابی، منطقی بیتی و مقایسه‌های علامت‌دار همراه با پرچم صفر پشتیبانی می‌کند.

## فایل‌ها

| فایل | هدف |
|---|---|
| `src/alu.vhd` | ALU ترکیبی کوچک |
| `tb/alu_tb.vhd` | بستر آزمون خودبررسی برای ALU |

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج
make clean  # پاک کردن build/
```
