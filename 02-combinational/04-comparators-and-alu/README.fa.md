# 04 — مقایسه‌کننده‌ها و یک ALU کوچک

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

عملگرهای مقایسه را روی انواع عددی به کار ببر، سپس یک ALU پارامتری بساز و هر کد عملیات را آزمون کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `localparam ADD = 2'b00;` | `type op_t is (OP_ADD, OP_SUB, OP_AND, OP_OR);` |

## مفاهیم

- مقایسه فقط میان انواع سازگار وجود دارد — unsigned را با unsigned مقایسه کن، نه با بردار.
- ALU یک case روی یک شمارشی کد عملیات است، با مسیر مشترک خروجی zero و carry.
- شمارشی‌کردن کد عملیات، اعداد جادویی را از بستر آزمون هم حذف می‌کند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. عملیات NOT و شیفت اضافه کن و مطمئن شو کدهای بی‌استفاده نتیجهٔ تعریف‌شده می‌دهند.
2. ALU را در یک حلقه با همهٔ کدهای ۴ بیتی راه بینداز و بررسی کن هیچ خروجی U یا X نیست.
