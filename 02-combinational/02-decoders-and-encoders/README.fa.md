# 02 — دیکدرها و انکدر اولویت‌دار

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک دیکدر one-hot و یک انکدر اولویت‌دار بنویس، سپس دیکدر هفت‌قطعه‌ای که در پروژهٔ پایانی به کار می‌آید.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `casez (sel)` | `case? sel is` |

## مفاهیم

- دیکدر یک case یا انتساب اندیسی از یک نوع کوچک به بیت‌های one-hot است.
- انکدر اولویت‌دار زنجیرهٔ if/elsif است — ترتیب، اولویت را می‌سازد و رفتار Z و X باید صریح باشد.
- case? در VHDL-2008 علامت - را بی‌اهمیت می‌گیرد، شبیه casez.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. دیکدر هفت‌قطعه‌ای را طوری کن که برای ۱۰ تا ۱۵ حروف A تا F و برای رقم نامعتبر خاموشی نشان دهد.
2. ورودی enable اضافه کن و توضیح بده چرا گیت‌کردن خروجی بهتر از گیت‌کردن ورودی است.
