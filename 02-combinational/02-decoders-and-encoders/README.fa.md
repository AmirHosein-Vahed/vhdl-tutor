# 02 — دیکدرها و انکدر اولویت‌دار

**وضعیت:** انجام‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> **آماده.** در این پوشه `make` را اجرا کنید.

## هدف

ساخت دیکدرهای باینری و انکدرهای اولویت‌دار با استفاده از تخصیص‌های منتخب و حلقه‌های ترتیبی.

## مفاهیم

- دیکدرهای باینری شاخص باینری را به یک بردار one-hot تبدیل می‌کنند.
- انکدرهای اولویت‌دار فعال‌ترین بیت با بالاترین ایندکس را پیدا می‌کنند.

## فایل‌ها

| فایل | هدف |
|---|---|
| `src/decoder_encoder.vhd` | دیکدر باینری ۳ به ۸ و انکدر اولویت‌دار ۸ به ۳ |
| `tb/decoder_encoder_tb.vhd` | بستر آزمون خودبررسی |

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج
make clean  # پاک کردن build/
```
