# 05 — پرهیز از لچ

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

الگوی انتساب ناقصی که لچ می‌سازد را بشناس و دو عادتی را یاد بگیر که جلوی آن را می‌گیرند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(*) if (en) y = a;  // latch` | `process (all) begin y <= '0'; if en = '1' then y <= a; end if; end process;` |

## مفاهیم

- اگر یک فرایند ترکیبی در همهٔ مسیرها خروجی را مقدار ندهد، ابزار باید مقدار قبلی را نگه دارد — این همان لچ است.
- انتساب پیش‌فرض در ابتدای فرایند همهٔ مسیرها را کامل می‌کند.
- when others در case برای کد سنتزپذیر اختیاری نیست، حتی اگر فکر کنی هرگز رخ نمی‌دهد.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. نسخهٔ لچ‌ساز را بنویس، سنتز کن (موضوع ۱۰) و لچ را در گزارش شبکه پیدا کن.
2. یک جنریک default اضافه کن که مقدار بازنشانی همهٔ خروجی‌ها را تعیین کند و حذفش کن تا تفاوت را ببینی.
