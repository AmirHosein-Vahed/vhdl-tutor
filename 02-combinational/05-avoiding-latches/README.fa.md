# 05 — پرهیز از لچ

**Status:** انجام‌شده · **موضوع:** [02-combinational — منطق ترکیبی](../README.fa.md) · [English](README.md)

> **آماده.** در این پوشه `make` را اجرا کنید.

## هدف

آشنایی با نحوهٔ استنتاج ناخواستهٔ لچ در صورت عدم تخصیص کامل در فرایندهای ترکیبی و یادگیری راه حل استاندارد در VHDL.

## مفاهیم

- قانون: همیشه یک مقدار پیش‌فرض به خروجی‌ها در ابتدای فرایند ترکیبی تخصیص دهید.

## فایل‌ها

| فایل | هدف |
|---|---|
| `src/latch_avoid.vhd` | فرایند ترکیبی با مقدار پیش‌فرض |
| `tb/latch_avoid_tb.vhd` | بستر آزمون خودبررسی |

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج
make clean  # پاک کردن build/
```
