# واژه‌نامه

اصطلاح انگلیسی، معادل فارسی، و معنایی که در این دوره به کار می‌رود.

| انگلیسی | فارسی | معنا |
|---|---|---|
| analysis | تحلیل | مرحلهٔ تجزیه و بررسی نوع در GHDL، پیش از بسط |
| architecture | معماری | پیاده‌سازی یک موجودیت |
| array | آرایه | مجموعه‌ای اندیس‌دار از عناصر هم‌نوع |
| assertion | ادعا | شرطی که باید برقرار باشد؛ در زمان اجرا یا به‌صورت صوری بررسی می‌شود |
| asynchronous reset | ریست ناهم‌زمان | ریستی که مستقل از ساعت و فوری اثر می‌کند |
| attribute | ویژگی | فراداده‌ای که به نوع، سیگنال یا موجودیت می‌چسبد (`'range`، `'event`) |
| backpressure | فشار معکوس | گیرنده با پایین آوردن `ready` به فرستنده می‌گوید توقف کند |
| BFM | مدل کارکردی گذرگاه | رویه‌هایی که یک پروتکل را «حرف می‌زنند» |
| block RAM | بلوک RAM | بلوک سخت‌افزاری حافظهٔ اختصاصی در FPGA |
| carry chain | زنجیرهٔ نقلی | مسیر سریع و اختصاصی جمع در FPGA |
| clock domain | دامنهٔ ساعت | منطقی که با یک منبع ساعت کلاک می‌شود |
| clock enable | فعال‌ساز ساعت | `if en = '1'` درون فرایند ساعت‌دار؛ جایگزین گیت‌کردن ساعت |
| component | کامپوننت | اعلان یک رابط که بعداً با پیکربندی متصل می‌شود |
| concurrent statement | دستور هم‌زمان | دستوری بیرون فرایند که به فرایندهای ضمنی بسط می‌یابد |
| configuration | پیکربندی | اعلانی که موجودیت‌ها را در یک سلسله‌مراتب به معماری‌ها متصل می‌کند |
| constant | ثابت | مقدار نام‌دار که در بسط تثبیت می‌شود |
| coverage | پوشش | شاهدی بر اینکه آزمون‌ها همان چیزی را آزمودند که باید |
| delta cycle | چرخهٔ دلتا | گام شبیه‌سازی با زمان صفر؛ سیگنال‌ها بین این گام‌ها به‌روز می‌شوند |
| DUT | طراحی تحت آزمون | طراحی یا دستگاه تحت آزمون |
| elaboration | بسط | ساختن سلسله‌مراتب، تعیین جنریک‌ها و اتصال درگاه‌ها |
| entity | موجودیت | رابط (نام، جنریک‌ها، درگاه‌ها) یک واحد طراحی |
| enumeration | شمارشی | نوعی با لیترال‌های نام‌دار (`type state_t is (IDLE, RUN)`) |
| FIFO | صف | بافر «اول ورود، اول خروج» |
| flip-flop | فلیپ‌فلاپ | یک بیت حالت ساعت‌دار |
| FSM | ماشین حالت | ماشین حالت متناهی |
| generic | جنریک | پارامتر زمان کامپایل یک موجودیت |
| GHW | GHW | قالب شکل موج GHDL که اطلاعات کامل نوع را نگه می‌دارد |
| handshake | دست‌دادن | پروتکلی که دو طرف در آن بر انجام انتقال توافق می‌کنند |
| instantiation | نمونه‌سازی | ساختن نمونه از یک موجودیت یا کامپوننت |
| latch | لچ | حافظهٔ ناخواستهٔ حساس به سطح؛ معمولاً یک باگ |
| latency | تأخیر | تعداد چرخه از ورودی تا خروجی متناظر |
| LUT | جدول درست‌نمایی | سلول منطقی پایهٔ FPGA |
| Mealy machine | ماشین میلی | ماشین حالتی که خروجی‌اش به حالت و ورودی وابسته است |
| metastability | فراماندگی | نمونه‌برداری ناپایدار وقتی سیگنال نزدیک لبهٔ ساعت تغییر می‌کند |
| Moore machine | ماشین مور | ماشین حالتی که خروجی‌اش فقط به حالت وابسته است |
| package | بسته | واحد کتابخانه‌ای برای انواع، ثابت‌ها و زیربرنامه‌های مشترک |
| pipeline | خط لوله | رجیستر میان مراحل منطقی برای افزایش توان عملیاتی |
| port | درگاه | سیگنال رابط یک موجودیت |
| port map | نگاشت درگاه | فهرست اتصال‌های یک نمونه |
| process | فرایند | ناحیهٔ ترتیبی کد؛ واحد حساسیت |
| PSL | PSL | زبان مشخصه‌سازی؛ ادعاهای زمانی در توضیحات |
| RAM / ROM | RAM / ROM | حافظهٔ خواندنی-نوشتنی / فقط-خواندنی |
| register | رجیستر | دسته‌ای از فلیپ‌فلاپ‌ها که یک مقدار را نگه می‌دارند |
| resolved type | نوع حل‌شده | نوعی با تابع حل برای چند راه‌انداز (`std_logic`) |
| reset | ریست / بازنشانی | برگرداندن رجیسترها به حالت معلوم |
| RTL | RTL | سطح انتقال رجیستر: توصیف رفتاری سنتزپذیر |
| scoreboard | جدول مرجع | نتایج انتظاری را نگه می‌دارد و ناهم‌زمان مقایسه می‌کند |
| sensitivity list | فهرست حساسیت | سیگنال‌هایی که فرایند را بیدار می‌کنند |
| sequential statement | دستور ترتیبی | دستور درون فرایند که به‌ترتیب اجرا می‌شود |
| signal | سیگنال | شیء ارتباطی که در پایان چرخهٔ دلتا به‌روز می‌شود |
| simulation | شبیه‌سازی | اجرای مدل بسط‌یافته در طول زمان |
| std_logic | std_logic | نوع منطقی ۹مقداریِ حل‌شدهٔ IEEE 1164 |
| subtype | زیرنوع | نسخهٔ محدودشدهٔ یک نوع (`natural`، `integer range 0 to 9`) |
| synthesis | سنتز | تبدیل RTL به شبکهٔ گیت و سلول |
| testbench | بستر آزمون | واحد طراحی بدون درگاه که DUT را می‌راند و بررسی می‌کند |
| test vector | بردار آزمون | یک مجموعه ورودی به‌همراه خروجی‌های انتظاری |
| throughput | توان عملیاتی | تعداد نتیجه در واحد زمان (معمولاً در هر ساعت) |
| tristate | سه‌حالته | خروجی `'Z'`؛ چند راه‌انداز روی یک گذرگاه |
| valid/ready | معتبر/آماده | جفت دست‌دادن استاندارد جریان داده |
| variable | متغیر | شیء محلی که درون فرایند بلافاصله به‌روز می‌شود |
| VCD | VCD | قالب شکل موج قابل‌حمل و بیتی |
| waveform | شکل موج | نمودار زمانی مقادیر سیگنال‌ها |
| Yosys | Yosys | چارچوب سنتز متن‌باز که در موضوع ۱۰ به کار می‌رود |
