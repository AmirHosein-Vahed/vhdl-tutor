# 01 — دست‌دادن valid/ready

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [09-interfaces — رابط‌ها و پروتکل‌ها](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

دست‌دادن سه‌حالته و یک بافر skid را پیاده کن که وقتی گیرنده متوقف می‌شود، یک بیت را جذب کند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `assign ready = !full;` | `ready <= '1' when count < DEPTH else '0';` |

## مفاهیم

- انتقال در لبهٔ ساعتی رخ می‌دهد که valid و ready هر دو بالا هستند؛ هیچ طرفی نباید valid را زودتر پس بگیرد.
- فشار معکوس: گیرنده ready را پایین می‌آورد؛ فرستنده باید داده و valid را پایدار نگه دارد.
- بافر skid آخرین بیت را رجیستر می‌کند تا ready ترکیبیِ پایین‌دست نتواند خط لولهٔ بالادست را متوقف کند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک FIFO با عمق ۴ و valid/ready در دو طرف بساز و در بستر آزمون الگوی توقف تصادفی بگذار.
2. بررسی‌ای اضافه کن که valid بدون انتقال پایین نرود، و یک بار در بستر آزمون نقضش کن.
