# 02 — گیرندهٔ UART

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [09-interfaces — رابط‌ها و پروتکل‌ها](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

چیزی را دریافت کن که موضوع ۰۴ می‌فرستد: تشخیص بیت شروع، نمونه‌برداری در میانهٔ بیت، خطای فریم و توازن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `if (!rx) state <= START;` | `if rx = '0' then state <= START; end if;` |

## مفاهیم

- لبهٔ نزولی خطِ بیکار-بالا را تشخیص بده، سپس در نیمهٔ دورهٔ بیت نمونه بگیر تا مرکز بیت را پیدا کنی.
- با نرخ ۱۶ برابر نمونه بگیر و رأی‌گیری کن، یا یک بار در مرکز هر بیت نمونه بگیر — تصمیم بگیر و مستند کن.
- framing_error وقتی بیت توقف ۱ نیست؛ parity_error وقتی توازن نمی‌خواند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. فرستنده و گیرنده را در یک بستر آزمون به هم وصل کن و ۱۰۰ بایت تصادفی بفرست.
2. نمونه‌بردار ۱۶ برابری با رأی‌گیری اکثریت اضافه کن و نرخ خطا را با نمونه‌برداری تکی مقایسه کن.
