# 04 — عبور از دامنهٔ ساعت

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [09-interfaces — رابط‌ها و پروتکل‌ها](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک سیگنال را میان دو ساعت بی‌ارتباط عبور بده — برای تک‌بیت درست، و صادقانه دربارهٔ چیزهایی که FIFO لازم دارند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `(* ASYNC_REG = "true" *) reg s1, s2;` | `attribute async_reg : string;` |

## مفاهیم

- برای یک بیت، دو فلیپ‌فلاپ در دامنهٔ مقصد؛ هرگز دو را ترکیبی با هم ترکیب نکن.
- یک گذرگاه چندبیتی را نمی‌توان بیت‌به‌بیت همگام کرد — از دست‌دادن، کد گری یا FIFO ناهم‌زمان استفاده کن.
- قیدهای false_path/CDC مستندسازی برای ابزار زمان‌بندی‌اند، نه راه‌حل.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک پالس ۱ هرتزی را از دامنهٔ ۱۰۰ مگاهرتز به ۳۳ مگاهرتز بفرست و پالس‌های دریافتی را بشمار.
2. عبور شمارندهٔ کد گری بساز و نشان بده چرا دودویی خراب می‌شود.
