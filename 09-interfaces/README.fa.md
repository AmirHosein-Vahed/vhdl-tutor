# 09-interfaces — رابط‌ها و پروتکل‌ها

**وضعیت:** 0 از 4 درس نوشته شده · [نقشهٔ راه](../../README.fa.md) · [English](README.md)

## چرا این موضوع

طراحی‌های واقعی بیشتر لوله‌کشی‌اند. دست‌دادنی را یاد بگیر که بیشتر گذرگاه‌های امروزی بر آن ساخته شده‌اند، سپس سه پروتکلی که با یک آنالیزور منطقی ارزان اشکال‌زدایی می‌شوند، و در پایان چیزی که هر تازه‌کاری را زمین می‌زند: عبور از دامنهٔ ساعت.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `assign ready = !full;` | `ready <= '1' when count < DEPTH else '0';` |
| `if (!rx) state <= START;` | `if rx = '0' then state <= START; end if;` |
| `spi_sclk <= ~spi_sclk;  // in a divider` | `sclk <= not sclk after PERIOD/2;` |
| `(* ASYNC_REG = "true" *) reg s1, s2;` | `attribute async_reg : string;` |

## پس از این موضوع می‌توانی

- پیاده‌سازی رابط valid/ready درست با فشار معکوس
- ساخت و دیکد UART و استاد SPI
- عبور ایمن از دامنهٔ ساعت یا دانستن اینکه کِی نمی‌توان

## پیش‌نیاز

ابتدا موضوع قبلی را تمام کن؛ هر موضوع مستقیماً روی قبلی ساخته می‌شود.
درس اول کل زنجیرهٔ ابزار را هم توضیح می‌دهد، بنابراین پیش‌زمینهٔ VHDL لازم نیست.
