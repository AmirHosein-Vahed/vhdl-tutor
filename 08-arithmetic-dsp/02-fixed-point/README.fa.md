## هدف

یک عدد Q1.7 را نمایش بده، دو تا را ضرب کن و نقطهٔ دودویی را همان‌جا که انتظار داری نگه دار.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `logic signed [15:0] x;  // Q1.15 by convention` | `signal x : sfixed(0 downto -15);` |
| `(a*b) >> 15` | `resize(a * b, sfixed(0 downto -15))` |

## مفاهیم

- ieee.fixed_pkg انواع ufixed و sfixed را با بازهٔ صریح مثل sfixed(0 downto -7) می‌دهد.
- ضرب دو مقدار Q1.7 نتیجهٔ Q2.14 می‌دهد؛ باید به بازهٔ دلخواه resize کنی.
- ممیز ثابت فقط عدد صحیح با مقیاس مستند است — بسته فقط کمک می‌کند آن را ردگیری کنی.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک ضرب‌کنندهٔ Q1.15 بساز و در بستر آزمون بررسی کن ۰٫۵ × ۰٫۵ = ۰٫۲۵.
2. ‎fixed_pkg را با پیاده‌سازی سادهٔ عدد صحیح مقایسه کن: نتیجهٔ یکسان، غافلگیری کمتر؟
