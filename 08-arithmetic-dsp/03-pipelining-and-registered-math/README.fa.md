# 03 — خط لوله و حساب رجیسترشده

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [08-arithmetic-dsp — حساب و پردازش سیگنال](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک مسیر دادهٔ ترکیبی چندسطحی را به خط لوله با زنجیرهٔ valid تبدیل کن و تأخیر را اندازه بگیر.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(posedge clk) begin v1 <= v; d1 <= d; end` | `process (clk) begin if rising_edge(clk) then v1 <= v; d1 <= d; end if; end process;` |

## مفاهیم

- هر مرحلهٔ خط لوله یک رجیستر است؛ بیت valid باید هم‌گام با داده تأخیر بخورد.
- تأخیر زیاد می‌شود اما توان عملیاتی یک نتیجه در هر ساعت می‌ماند — این همان معامله است.
- ‎for generate با یک شیفت‌رجیسترِ مرجع، بستر آزمون را هم‌تراز نگه می‌دارد.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک خط لولهٔ چهارمرحله‌ای به ALU اضافه کن و ثابت کن خروجی پس از N چرخه با مرجع بدون خط لوله یکسان است.
2. یک حباب (valid = 0) وارد کن و بررسی کن درست منتشر می‌شود.
