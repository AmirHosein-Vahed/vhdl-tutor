# 02 — پیکربندی‌ها

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [06-modularity — پیمانه‌ای‌سازی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

از اعلان پیکربندی استفاده کن تا اتصال موجودیت‌ها به معماری‌ها یک‌جا انجام شود، نه با ویرایش هر نمونه‌سازی.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| ``ifdef SIM / `else` | `configuration sim_cfg of top is ...` |

## مفاهیم

- عبارت configuration cfg of top is for rtl ... end for; یک سلسله‌مراتب کامل را متصل می‌کند.
- پیکربندی به یک شبکه اجازه می‌دهد نسخهٔ شبیه‌سازی و سنتز داشته باشد.
- بیشتر ابزارها پشتیبانی می‌کنند اما تیم‌های کمی استفاده می‌کنند — بدان که وجود دارد و چرا.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. دو معماری (rtl و behavioural) و دو پیکربندی بساز؛ هر دو را از یک بستر آزمون اجرا کن.
2. در یک بند توضیح بده پیکربندی کِی از جنریک بهتر است.
