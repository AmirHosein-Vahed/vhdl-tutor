# 05 — generate و منطق شرطی

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [06-modularity — پیمانه‌ای‌سازی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

با for generate و if generate ساختار پارامتری بساز و بفهم که این‌ها بسط می‌یابند و اجرا نمی‌شوند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `generate for (genvar i=0; i<N; i++)` | `gen : for i in 0 to N-1 generate` |
| `if (WIDTH > 8) begin ... end` | `gen_if : if WIDTH > 8 generate` |

## مفاهیم

- ‎gen : for i in 0 to N-1 generate سخت‌افزار را تکرار می‌کند؛ متغیر حلقه ثابت است.
- ‎if generate سخت‌افزار را در بسط وارد یا حذف می‌کند — برخلاف دستور if که مالتی‌پلکسر است.
- برچسب generate در VHDL-2008 اختیاری و در استانداردهای قدیمی لازم است؛ به‌هرحال بنویس.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک جمع‌کنندهٔ N بیتی از N جمع‌کنندهٔ کامل با for generate بساز.
2. با if generate یک رجیستر خط لولهٔ اختیاری اضافه کن و تأخیر تغییرکرده را اندازه بگیر.
