# 03 — بسته‌ها و ثابت‌ها

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [06-modularity — پیمانه‌ای‌سازی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

کپی‌کردن تعریف ثابت‌ها را متوقف کن: انواع، ثابت‌ها و توابع مشترک را در یک بسته بگذار و همه‌جا use کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| ``include "defs.vh"` | `use work.defs_pkg.all;` |

## مفاهیم

- اعلان بسته شامل انواع، ثابت‌ها و مشخصات زیربرنامه‌ها است؛ بدنهٔ بسته پیاده‌سازی را دارد.
- ثابت‌های معوق (constant C : integer;) مشخصه را از مقدار جدا می‌کنند — یک بار در بدنه مقدار می‌گیرند.
- ‎use work.pkg.all معادل include در C است، اما نوع‌بررسی‌شده و مستقل از ترتیب.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. نوع کد عملیات ALU و ثابت نرخ باد UART را به بستهٔ پروژه منتقل کن.
2. تابع log2 به بسته اضافه کن و برای تعیین اندازهٔ شمارنده‌ها به کار ببر.
