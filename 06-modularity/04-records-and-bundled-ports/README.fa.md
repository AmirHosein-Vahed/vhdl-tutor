# 04 — رکوردها و درگاه‌های دسته‌بندی‌شده

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [06-modularity — پیمانه‌ای‌سازی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

سیگنال‌های مرتبط را در یک رکورد دسته کن تا port map از بیست خط نام تکی خلاص شود.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `typedef struct packed {...} axi_t;` | `type axi_t is record data : std_logic_vector(31 downto 0); valid : std_logic; end record;` |

## مفاهیم

- نوع رکورد فیلدها را گروه می‌کند؛ signal bus : axi_t; و سپس bus.data و bus.valid.
- رکوردها port map را بسیار کوتاه و رابط را خودمستند می‌کنند.
- برخی ابزارهای سنتز با رکورد در درگاه‌های سطح بالا مشکل دارند — درون طراحی نگهش دار و در مرز تخت کن.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. یک رکورد valid/ready تعریف کن و در ماژول دست‌دادن موضوع ۰۹ به کار ببر.
2. تابعی بنویس که رکورد را برای درگاه سطح بالا به بردار تخت تبدیل کند.
