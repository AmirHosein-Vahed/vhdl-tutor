# 01 — مبانی VUnit

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [11-verification — چارچوب‌های راستی‌آزمایی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک بستر آزمون دستی را به بستر VUnit تبدیل کن، دو مورد آزمون ثبت کن و با python run.py اجرا کن.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `// no framework` | `uv run python run.py` |

## مفاهیم

- VUnit بسترهای آزمون را از run.py کشف می‌کند که فایل‌های منبع و کتابخانه‌ها را فهرست می‌کند.
- ‎test_runner به‌همراه test_case یک اجرای شبیه‌سازی با چند آزمون نام‌دار می‌دهد.
- ‎check_equal جای assert دستی را می‌گیرد و با گزارش VUnit یکپارچه می‌شود.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. مورد آزمونی اضافه کن که خطا تزریق می‌کند و آن را should_fail علامت بزن.
2. سطح بالای دوم (FIFO) را اضافه کن و هر دو مجموعه را با یک فرمان اجرا کن.
