## هدف

از بستهٔ تصادفی OSVVM استفاده کن تا به حالت‌های گوشه‌ای برسی که بردارهای دستی هرگز نرسیدند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `$urandom_range(0, 15)` | `RandInt(0, 15)` |

## مفاهیم

- ‎RandomPkg توابع RandInt و RandSlv و توزیع‌ها را با دانهٔ قابل تکرار می‌دهد.
- Scoreboard نتایج انتظاری را ذخیره و به‌صورت ناهم‌زمان مقایسه می‌کند.
- پوشش کارکردی به این پاسخ می‌دهد که «آیا آنچه را می‌خواستم آزمودم؟»، نه «آیا قبول شد؟».

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. عملوندها و کدهای ALU را با دانهٔ ثابت برای ۱۰٬۰۰۰ چرخه تصادفی کن، سپس دانه را عوض کن.
2. یک coverpoint ساده اضافه کن که بشمارد هر کد عملیات چند بار آزموده شد.
