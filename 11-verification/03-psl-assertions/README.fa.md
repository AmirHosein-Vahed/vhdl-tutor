# 03 — ادعاهای PSL

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [11-verification — چارچوب‌های راستی‌آزمایی](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

ویژگی‌های زمانی را کنار RTL بنویس — «پس از درخواست، تأیید حداکثر تا ۴ چرخه» — و بگذار GHDL بررسی کند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `assert property (@(posedge clk) req \|-> ##[1:4] ack);` | `-- psl assert always req -> eventually[1 to 4] ack;` |

## مفاهیم

- PSL در توضیحات VHDL زندگی می‌کند، پس برای سنتز و ابزارهای دیگر نامرئی است.
- ‎default clock is rising_edge(clk); و سپس assert always req -> eventually! ack;.
- GHDL در تحلیل به ‎-fpsl و برای جمع‌آوری نتایج به ‎--psl-report=... نیاز دارد.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. به فرستندهٔ UART ادعای PSL اضافه کن که بیت شروع همیشه بیت توقف داشته باشد.
2. RTL را عمداً خراب کن و مطمئن شو خود ادعا آن را می‌گیرد، نه بستر آزمون.
