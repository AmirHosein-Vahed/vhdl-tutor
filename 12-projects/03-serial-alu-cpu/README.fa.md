**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [12-projects — پروژه‌های پایانی](../README.fa.md) · [English](README.md)

## هدف

UART، تحلیل‌گر فرمان، فایل رجیستر و ALU را در یک ماشین انباشتگر کوچک ترکیب کن که از ترمینال رانده شود.

## مفاهیم

- قالب دستور: کد عملیات، اندیس رجیستر، مقدار فوری — در یک چرخه دیکد و در چرخهٔ بعد اجرا.
- تحلیل‌گر فرمان یک ماشین حالت روی بایت‌های ASCII است، با بافر کوچکی برای عملوند.
- بستر آزمون همان جریان بایتی را می‌فرستد که ترمینال می‌فرستد، پس CPU بدون سخت‌افزار آزمون‌پذیر است.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. پرش شرطی اضافه کن و حلقه‌ای پیاده کن که مجموع ۱ تا N را حساب کند.
2. دستور HALT اضافه کن و بستر آزمون را وادار کن تخلیهٔ نهایی رجیسترها را بررسی کند.
