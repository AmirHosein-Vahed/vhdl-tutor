## مفاهیم

- زمان‌بندی همان شمارنده است: افقی ۰ تا ۷۹۹ و عمودی ۰ تا ۵۲۴، با پالس‌های همگام در بازه‌های ثابت.
- پیکسل‌های دیدنی ناحیهٔ میان back porch و front porch‌اند — بقیه خاموشی است.
- دادهٔ پیکسل باید رجیستر شود: رنگ پیکسل N وقتی ظاهر می‌شود که آدرس N+1 خوانده می‌شود.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. شطرنجی و یک نوار متحرک رسم کن، سپس با جنریک بین الگوها جابه‌جا شو.
2. یک اسپرایت در بلوک RAM ذخیره کن و با کلیدهای جهت (دیبانس‌شده) جابه‌جایش کن.
