# 10-synthesis-awareness — آگاهی از سنتز

**وضعیت:** 0 از 3 درس نوشته شده · [نقشهٔ راه](../../README.fa.md) · [English](README.md)

## چرا این موضوع

شبیه‌سازی سخت‌افزار نیست. این موضوع عمداً کوتاه و اختیاری است: به‌اندازه‌ای که کد سنتزناپذیر را بشناسی و ببینی RTL‌ات به چه تبدیل می‌شود.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `#10 y = a;  // ignored by synthesis` | `y <= a after 10 ns;  -- simulation only` |
| `always @(*) case (s)` | `process (all) begin case s is` |
| `quartus_map / vivado synth_design` | `yosys -m ghdl -p '...; synth; stat'` |

## پس از این موضوع می‌توانی

- تشخیص کد سنتزپذیر از کد مخصوص شبیه‌سازی
- پیش‌بینی اینکه کدام ساختار RAM یا مالتی‌پلکسر یا لچ می‌سازد
- خواندن گزارش stat در Yosys

## پیش‌نیاز

ابتدا موضوع قبلی را تمام کن؛ هر موضوع مستقیماً روی قبلی ساخته می‌شود.
