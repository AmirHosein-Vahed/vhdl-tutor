# 02 — استنتاج سخت‌افزار

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [10-synthesis-awareness — آگاهی از سنتز](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

ساختارهای آشنا را به آنچه ابزار واقعاً می‌سازد نگاشت کن: LUT، زنجیرهٔ نقلی، بلوک RAM و لچ.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(*) case (s)` | `process (all) begin case s is` |

## مفاهیم

- ‎case روی یک سیگنال درخت مالتی‌پلکسر می‌سازد؛ and/or پهن به LUT تبدیل می‌شود.
- عملگر + روی unsigned زنجیرهٔ نقلی می‌سازد؛ شیفت با ثابت سیم‌کشی رایگان است.
- آرایه با خواندن/نوشتن هم‌زمان بلوک RAM می‌سازد؛ خواندن ناهم‌زمان RAM توزیع‌شده.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. همان مالتی‌پلکسر را با when/else و with/select و case بنویس؛ سه شبکه را مقایسه کن.
2. خواندن یک RAM را ناهم‌زمان کن و گزارش منابع را تفاوت بگیر.
