> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک پروتکل را یک بار به‌صورت مور و یک بار میلی پیاده کن و دقیقاً ببین در شکل موج چه تغییر می‌کند.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `localparam IDLE = 2'd0;` | `type state_t is (IDLE, RUN);  signal state : state_t;` |

## مفاهیم

- خروجی مور فقط به حالت بستگی دارد؛ خروجی میلی به حالت و ورودی، پس یک چرخه زودتر واکنش می‌دهد و نویزپذیرتر است.
- سبک سه‌فرایندی: رجیستر حالت، تابع حالت بعد، تابع خروجی. سبک دوفرایندی دو مورد آخر را ادغام می‌کند.
- نوع شمارشی (type state_t is (IDLE, RUN)) شکل موج خوانا و حالت‌های بررسی‌شده توسط کامپایلر می‌دهد.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. نمودار حالت هر دو نسخه برای آشکارساز دنبالهٔ 1011 را بکش و یکی را پیاده کن.
2. ورودی timeout اضافه کن که از هر حالت به IDLE برگردد.
