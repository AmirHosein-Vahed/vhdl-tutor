# 03 — ماشین حالت به‌همراه مسیر داده: دیبانسر

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [04-state-machines — ماشین‌های حالت](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

یک دیبانسر واقعی دکمه با فیلتر شمارنده‌ای و آشکارساز لبه بساز — نخستین ماشین حالتی که مسیر داده دارد.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `always @(posedge clk) q1 <= q0;` | `process (clk) begin if rising_edge(clk) then q1 <= q0; end if; end process;` |

## مفاهیم

- نمونه‌برداری از ورودی مکانیکی به فیلتر «پایدار برای N نمونه» نیاز دارد، نه تأخیر.
- آشکارسازی لبه همان q1 <= q0; rise <= q0 and not q1; است — یک رجیستر و یک مقایسه.
- شمارندهٔ فیلتر را از حالت ماشین جدا کن تا هر کدام جداگانه آزمون‌پذیر باشند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. زمان دیبانس را جنریکی بر حسب میلی‌ثانیه کن و تعداد را از CLK_HZ به دست آور.
2. تشخیص فشار طولانی (یک ثانیه نگه‌داشتن) را به‌عنوان خروجی دوم اضافه کن.
