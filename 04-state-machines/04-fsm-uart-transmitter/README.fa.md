# 04 — ماشین حالت به‌همراه مسیر داده: فرستندهٔ UART

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [04-state-machines — ماشین‌های حالت](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

ماشین حالت کلاسیک نرخ باد را طراحی کن: بیکار، شروع، هشت بیت داده (کم‌ارزش‌ترین اول)، توقف — با پرچم busy برای فشار معکوس.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `if (baud_tick) state <= ...;` | `if baud_tick = '1' then state <= ...;` |

## مفاهیم

- مولد نرخ باد شمارنده‌ای تا CLK_HZ/BAUD است؛ ماشین حالت روی شمارش پایانی جلو می‌رود.
- شیفت‌رجیستر کم‌ارزش‌ترین بیت را اول می‌فرستد؛ ماشین حالت فقط زمان شیفت را تعیین می‌کند.
- busy و ready یک دست‌دادن است: فراخواننده نباید تا بالا بودن busy بایت جدید شروع کند.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. در شکل موج، دورهٔ بیت را برای ۱۱۵۲۰۰ باد از ساعت ۵۰ مگاهرتز بررسی کن.
2. جنریک parity اضافه کن و بستر آزمون را وادار کن فریم دریافتی را دیکد کند.
