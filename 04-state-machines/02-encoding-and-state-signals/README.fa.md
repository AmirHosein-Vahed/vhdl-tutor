# 02 — کدگذاری حالت و ماشین ایمن

**وضعیت:** برنامه‌ریزی‌شده · **موضوع:** [04-state-machines — ماشین‌های حالت](../README.fa.md) · [English](README.md)

> این درس هنوز نوشته نشده است. هدف، مفاهیم و تمرین‌های زیر قرارداد آن هستند
> و کد هنگام تکمیل موضوع اضافه می‌شود.

## هدف

کنترل کن حالت‌ها چگونه کدگذاری شوند، یک گذار پیش‌فرض اضافه کن و بفهم when others چه هزینه‌ای دارد (هیچ).

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `(* fsm_encoding = "one_hot" *)` | `attribute enum_encoding : string;` |

## مفاهیم

- ویژگی enum_encoding مخصوص هر فروشنده است؛ دودویی پیش‌فرض است و one-hot روی FPGA سریع‌تر.
- انتساب پیش‌فرض next_state <= state ماشین را از حالت غیرمجاز نجات می‌دهد.
- when others روی یک نوع شمارشی در شبیه‌سازی ناممکن است اما پس از سنتز ضروری.

## اجرا

```bash
make        # تحلیل، بسط و اجرای بستر آزمون خودبررسی
make wave   # همان، به‌همراه باز کردن شکل موج در Surfer یا GTKWave
make clean  # پاک کردن build/
```

## تمرین‌ها

1. با یک ویژگی، کدگذاری one-hot را اجبار کن و رجیستر حالت سنتزشده را مقایسه کن.
2. انتساب پیش‌فرض را بردار، در شبیه‌سازی حالت غیرمجاز را تحمیل کن و تفاوت را ببین.
