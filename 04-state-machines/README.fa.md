# 04-state-machines — ماشین‌های حالت

**وضعیت:** 0 از 4 درس نوشته شده · [نقشهٔ راه](../../README.fa.md) · [English](README.md)

## چرا این موضوع

هر ماشین حالتی که در وریلاگ نوشته‌ای در VHDL هم کار می‌کند، اما شکل اصیل آن متفاوت است: یک نوع شمارشی به‌جای localparam و جدایی روشن میان رجیستر حالت و منطق حالت بعد.

## از وریلاگ به VHDL

| Verilog / SystemVerilog | VHDL |
|---|---|
| `localparam IDLE = 2'd0;` | `type state_t is (IDLE, RUN);  signal state : state_t;` |
| `(* fsm_encoding = "one_hot" *)` | `attribute enum_encoding : string;` |
| `always @(posedge clk) q1 <= q0;` | `process (clk) begin if rising_edge(clk) then q1 <= q0; end if; end process;` |
| `if (baud_tick) state <= ...;` | `if baud_tick = '1' then state <= ...;` |

## پس از این موضوع می‌توانی

- نوشتن ماشین حالت سه‌فرایندی از حافظه
- انتخاب کدگذاری و توجیه آن
- ترکیب ماشین حالت با مسیر داده (دیبانسر، UART)
